# CO₂ Emission Prediction

This project uses a linear regression model to predict CO₂ emissions based on three features: engine size, number of cylinders, and fuel consumption.

## How It Works

1. Download the dataset from this Google Drive link: [https://drive.google.com/file/d/105gw7Zv-3IJrnpl0ZdfyY6WDZAVBIcZY/view?usp=sharing].
2. Place the CSV file in the same directory as the script.
3. Run the script. It will ask you to enter your car’s engine size, number of cylinders, and fuel consumption, and it will predict the CO₂ emissions per kilometer.

## Dataset

The dataset is crucial for the model. Please download it from the link above and place it in the same folder as the script.

## How to Run

After downloading the dataset, simply execute the script. Follow the prompts, and the model will provide the CO₂ emissions prediction.
